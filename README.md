# Movie Search App

A simple web application to search for movies using The Movie Database (TMDB) API.  
Built with HTML, CSS and JavaScript.

---

## Features

- Search movies by title
- Shows poster, title, release year and rating
- Displays a short overview for each movie
- Clean, responsive layout

---

## Tech Stack

- HTML
- CSS
- JavaScript
- TMDB API (v3)

---
